## РЕКОМЕНДОВАНІ ОСНОВНІ НАЛАШТУВАННЯ (для VESC BMS)

### Обов’язкові:

1. ✅ Communication Type (0x9239) = 0x11 (SPI CRC)
2. ✅ REG1 Config (0x9236) = 0x0B (3.3V)
3. ✅ REG2 Config (0x9236) = 0xC0 (5.0V)
4. ✅ VCell Mode (0x9304) = Маска підключених клітинок (обов'язково для налаштування S-конфігурації)
5. ✅ CC Gain (0x91A8) = 7.4768 / R_sense (для твого sense резистора)

### Конфігурація VCell Mode (0x9304) для BQ76942 (до 10S):
Для BQ76942 обов'язково мають бути підключені клітинки 1, 2 та 10. Невикористані середні клітинки замикаються (short) на попередні, а відповідні біти в регістрі вимикаються (значення 0), щоб запобігти CUV помилкам.
- **10S (Всі клітинки):** `0x03FF` (Біти 1-10 включені)
- **8S (Без VC8, VC9):** `0x027F` (Біти 1-7 = 1, Біти 8-9 = 0, Біт 10 = 1)
- **7S (Без VC7, VC8, VC9):** `0x023F` (Біти 1-6 = 1, Біти 7-9 = 0, Біт 10 = 1)
- **6S (Без VC6, VC7, VC8, VC9):** `0x021F` (Біти 1-5 = 1, Біти 6-9 = 0, Біт 10 = 1)

### Дуже рекомендовані:

1. ⚠️ COV Threshold (0x9360) = 4275 (4.275V)
2. ⚠️ CUV Threshold (0x9366) = 2800 (2.8V)
3. ⚠️ SCD Threshold (0x938E) = >200A
4. ⚠️ OCD1/OCD2/OCD3 Thresholds = 100A / 150A / 200A
5. ⚠️ Cell Open Wire Detection (0x926D) = Enable
6. ⚠️ Load Detect (0x9274) = Enable

### Опціональні (покращення):

1. 🔧 Autonomous Recovery = Enable (0x9244-0x924F)
2. 🔧 Voltage Imbalance Detection (0x92AC, 0x92AD)
3. 🔧 Thermistor Configuration (всі 8-9 датчиків)
4. 🔧 Cell Balancing (якщо є резистори на платі)
